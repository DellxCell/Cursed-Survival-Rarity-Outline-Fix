# Cursed Survival Rarity Outline Fix

Dropped loot in **Cursed Survival** shows its rarity colour again, a mod for **Black Ops 7 Zombies** made for **Kronos**.

In Cursed Survival, dropped loot shows a **grey outline** no matter how rare it is: weapons, salvage, equipment and rewards all look Common. This mod brings back the normal rarity colours (green, blue, purple, orange and so on), the same as in regular Survival.

**Website:** https://dellxcell.github.io/Cursed-Survival-Rarity-Outline-Fix/

## Download

Get the zip from **[Releases](https://github.com/DellxCell/Cursed-Survival-Rarity-Outline-Fix/releases)** and follow [Install](#install) below.

## Features

- Rarity colours back on dropped loot in **Cursed Survival matches only**; other modes are untouched
- Works with any map and any relics, including Mister Peeks Mayhem
- No Kronos or game files are replaced, so nothing shows as "Outdated" in the launcher

**How it works**

The dropped items in Cursed Survival carry the same rarities as in Survival; only the outline colour is missing. The difference is one game setting that Kronos turns on for Survival but leaves off for Cursed Survival. This mod turns that setting on in Cursed Survival matches only. Everything else stays as it is.

## Requirements

- Black Ops 7 with **Kronos** set up (run the Kronos launcher at least once)

## Install

1. Download **[Cursed-Survival-Rarity-Outline-Fix-1.0.zip](https://github.com/DellxCell/Cursed-Survival-Rarity-Outline-Fix/releases/download/v1.0/Cursed-Survival-Rarity-Outline-Fix-1.0.zip)** from the [latest release](https://github.com/DellxCell/Cursed-Survival-Rarity-Outline-Fix/releases/latest).
2. Close Black Ops 7 and KronosLauncher completely.
3. Extract the zip into `C:\Kronos\cod25\kronos\mods`. You should end up with `C:\Kronos\cod25\kronos\mods\cursed_rarity_outline_fix\mod.json`, plus the `scripts` folder next to it.
4. Launch the game through Kronos as usual.

> [!NOTE]
> To remove it, delete `C:\Kronos\cod25\kronos\mods\cursed_rarity_outline_fix`.
