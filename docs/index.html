Cursed Survival Rarity Outline Fix1.0

Dropped loot in Cursed Survival shows its rarity colour again, instead of a grey outline. A Black Ops 7 Zombies mod made for Kronos.

Cursed Survival onlyAny map, any relicNo game files replacedFree
Download Source code Not on the Kronos Workshop: install it by hand in a minute.

What it fixes

Grey outlines on every drop in Cursed Survival

  • Rarity colours backGreen, blue, purple, orange and so on, the same as in regular Survival.
  • On every dropWeapons, salvage, equipment and rewards all show their real rarity.

How it works

One setting, one mode

  • Same loot, missing colourCursed Survival drops carry the same rarities as Survival; only the outline colour is missing.
  • One game settingKronos turns it on for Survival but leaves it off for Cursed Survival. This mod turns it on in Cursed Survival matches.

Safe to keep on

It stays out of the way

  • Cursed Survival onlyOther modes are untouched.
  • Any map and relicIncluding Mister Peeks Mayhem.
  • Nothing replacedNo Kronos or game files are replaced, so nothing shows as Outdated in the launcher.

Get started

  1. Set up Kronos and run its launcher at least once.
  2. Download Cursed-Survival-Rarity-Outline-Fix-1.0.zip from the latest release.
  3. Close Black Ops 7 and KronosLauncher, then extract the zip into C:\Kronos\cod25\kronos\mods. You should end up with mods\cursed_rarity_outline_fix\mod.json.
  4. Launch through Kronos and play Cursed Survival.
